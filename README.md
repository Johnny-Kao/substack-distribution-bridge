# Substack Distribution Bridge

GitHub is a public AI-independent entry point, generic SOP and workflow scheduler. Cloudflare is the **private** runtime, holding state and credentials. Public GitHub never stores individual targets, private search terms, interaction history or draft comments. Only the authorized operator can approve public writes.

Scheduled workflows perform read-only discovery. Publishing is disabled in this initial cloud version pending independent cloud read/write acceptance and approval gate validation.

Any agent should read AGENTS.md. No Substack login/session setup is needed on the agent side.

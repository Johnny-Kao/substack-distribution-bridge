# General SOP

Discovery -> deterministic validation and filtering -> semantic review of small shortlist -> draft -> authorization -> execution -> readback verification -> private learning record. Search schedules and interactions are separate. Retry only after examining prior status. On publication failure do not blindly retry. For Notes, experiment with different short hooks, including an optional direct article link. Personal scoring weights and targets remain private.

Local validation 2026-10-23: five Likes, one comment and one Note were published and independently reread. Cloud implementation needs its own acceptance tests.
